## Коммерческий проект

### Сервис отзывов для интеграции на сайты компаний (Laravel)

Backend-сервис для сбора и отображения отзывов клиентов через интегрируемый виджет.

Технологический стек:

- PHP 8.4
- Laravel 13
- PostgreSQL
- Docker
- Laravel Sail
- Laravel Sanctum
- Scramble OpenAPI
- FormRequest

Реализовано:

- разработка REST API;
- система авторизации через Laravel Sanctum;
- валидация входящих запросов через FormRequest;
- проектирование структуры базы данных;
- автоматическая генерация документации API;
- настройка Docker-окружения для разработки.
