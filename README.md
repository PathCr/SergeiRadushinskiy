## Коммерческий проект

### Сервис отзывов для интеграции на сайты компаний (Laravel)

Backend-сервис для сбора, хранения и отображения отзывов клиентов через интегрируемый виджет.

### Технологический стек

* PHP 8.4
* Laravel 13
* PostgreSQL
* Docker
* Laravel Sail
* Laravel Sanctum
* Eloquent ORM
* FormRequest
* Policies
* PHPUnit
* Scramble OpenAPI
* Git
* Linux Ubuntu

### Реализовано

* Проектирование структуры базы данных и разработка миграций.
* Разработка REST API для работы с компаниями, пользователями и отзывами.
* Реализация аутентификации и авторизации через Laravel Sanctum.
* Настройка разграничения доступа с использованием Laravel Policies.
* Работа с базой данных через Eloquent ORM.
* Валидация входящих данных через FormRequest.
* Покрытие ключевого функционала автоматическими тестами.
* Автоматическая генерация документации OpenAPI через Scramble.
* Контейнеризация проекта с использованием Docker и Laravel Sail.
* Разработка в Linux-среде (Ubuntu).
